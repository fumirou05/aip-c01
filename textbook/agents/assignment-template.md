# ページペア割り当てテンプレート

以下を埋めてページペア執筆者、レビュー担当、または昇格ページペア執筆者へ渡す。

```text
役割: ページペア執筆者 | ページペアレビュー担当 | 昇格ページペア執筆者
Pair ID:
Task ID:
対応Skills:
対象Task文書:
literal出力パス:
supplimental出力パス:
literal目次の収録要素:
supplimental目次の補助要素:
必ず確認する公式URL:
追加で確認すべき変更されやすい事項:
編集してよいファイル:
編集禁止ファイル:
昇格回数: 0 | 1
直前のレビュー報告: （昇格執筆の場合は全文）
完了時に報告する事項:
```

## 執筆者への共通依頼文

```text
textbook/AGENTS.mdとtextbook/agents/page-pair-writer.mdに従ってください。
割り当てられたliteral／supplimentalの2ファイルだけを編集してください。
テンプレートは出発点として使い、形式の厳密な一致より正確さと理解しやすさを優先してください。
先にliteral pageを公式資料から作成し、その理解を試験上の比較・判断へつなぐsupplimental pageを作成してください。
必要な場合だけ図や表を使い、本文でも意味を説明してください。
```

## レビュー担当への共通依頼文

```text
textbook/AGENTS.mdとtextbook/agents/page-pair-reviewer.mdに従ってください。
対象ページの執筆完了後にレビューし、割り当てられた2ファイル以外は編集しないでください。
テンプレート一致ではなく、公式根拠、Task・Skillsの網羅、literal／supplimentalの境界、試験に必要な理解、読みやすさを判定してください。
必ずPASS、FIX、ESCALATEのいずれかを返してください。小さく安全な修正は直接反映してFIXとし、構造的な問題だけをESCALATEとしてください。
```

## 昇格執筆者への共通依頼文

```text
textbook/AGENTS.mdとtextbook/agents/page-pair-writer-high.mdに従ってください。
これはレビューでESCALATEとなったページペアの初回かつ唯一の昇格です。
直前のレビュー報告を作業指示として、AWS公式資料で再検証し、割り当てられた2ファイルだけを修正してください。
指摘の解消に必要な範囲は再構成してよいですが、指摘と無関係な全面改稿は行わないでください。
完了後は、解消した指摘、公式根拠、未解決事項、再レビューの重点を報告してください。
```
