# ドメイン別ノート

ノートは「サービスの説明」だけでなく、次の形式で残す。

1. 何を解決するものか
2. どの要件で選ぶか
3. 似たサービス・方式との違い
4. セキュリティ、性能、可用性、コスト上の注意点
5. 実装例または構成例
6. 公式資料と最終確認日
